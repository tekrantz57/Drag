# Contributions And Support

Drag is a maintainer-controlled experimental beta. Beta bug reports are welcome
through [GitHub Issues](https://github.com/tekrantz57/Drag/issues/new/choose).
Use the Beta Bug Report form for installation problems, crashes, incorrect
results, or a workflow that cannot be completed. Include the version, operating
system, whether you used simulation or hardware, and steps to reproduce it.

This is a limited bug-report channel, not a guaranteed support service. Pull
requests and general feature requests are not currently being accepted while
physical track validation is still underway.

The MIT license permits forks and independent modification. A public fork is
not an endorsed Drag installation, and its hardware behavior and race results
must be validated independently.

When discussing Drag outside this repository, do not publish operator databases,
serial logs, generated reports, credentials, local machine configuration, or
screenshots containing private racer information. Useful technical context
includes the Drag commit, DragMC firmware version, operating system or Wine
version, CPU architecture, Mega or clone model, sensor wiring, and concise
reproduction steps.
